# OpenReview mascot concept

An original black-and-white character for [OpenReview](https://github.com/imMamdouhaboammar/openreview)

## The idea

The character is provisionally nicknamed **Rovi**

- The magnifying-glass eye hints at inspecting a pull request
- The checkmark-shaped beak hints at verified findings
- The folded-page ear hints at a code diff or review note
- The asymmetrical silhouette and small smile make it recognizable without text

## Usage guidance

- Keep at least 8% empty space around the symbol
- Preserve the black and white palette (`#080808`, `#FFFFFF`)
- Use the icon alone at small sizes and the wordmark at larger sizes
- Keep the facial marks intact when resizing
- For the GitHub repository itself, the horizontal logo can be used in README; the GitHub App avatar can use the square icon

This is a draft identity proposal, not yet merged into the project repository
